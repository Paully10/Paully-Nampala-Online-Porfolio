# Paully HN Nampala — Personal Portfolio

Dark, technical four-page portfolio inspired by the supplied visual reference.

## Run locally
Open this folder in VS Code and use **Live Server** on `index.html`.

## Pages
- Profile — `index.html`
- Skills — `skills.html`
- Projects — `projects.html`
- Contact — `contact.html`

## Notes
- Social links use real brand icons and colored accents.
- Instagram and GitHub point to the supplied profiles.
- Facebook and X currently land on their main login/home pages as requested.
- The contact form uses FormSubmit to deliver messages to `paullynampala@gmail.com`; the first submission may require FormSubmit's email activation/confirmation.
- The theme toggle persists the user's choice in local storage.
- Resume is currently included as DOCX. Replace it with a PDF later if desired.
